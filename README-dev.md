# Zorn Novum Website

Private development repository for the Zorn Novum public website.

## Development posture

- Build and review on the `development` branch.
- Public website claims require approval before production publication.
- Do not place credentials, proprietary trading logic, private operating data, or restricted internal material in this repository.
- Production DNS changes and public deployment require separate approval.

## Current structure

- `index.html` — initial single-page informational site
- `styles.css` — responsive styling
- `assets/` — approved website graphics

The current site content is a development draft and is intentionally marked noindex until public release is approved.
