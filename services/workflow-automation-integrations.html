Before you inquire

Common questions

What is an MCP connection for?

Model Context Protocol (MCP) lets a compatible AI client use tools exposed by a server. A project defines which tools are exposed and which systems they can access; it does not imply unrestricted access or compatibility with every client.

Can you connect any two applications?

Each connection needs assessment. The applications must provide suitable supported interfaces and permissions for the requested workflow. Some ideas may need a separately scoped first stage or may not be a fit.

Are AI usage and API subscription fees included?

Only as expressly stated in the proposal. Third-party usage, paid APIs and limits are separately quoted or explicitly capped. Recurring management and variable usage charges follow the agreement.

Should I send API keys with my request?

No. Start with application names and a general description of the workflow. Any credentials or authorization needed for an accepted project must follow the handling arrangements agreed for that work.

Tell us what you want to improve.

Describe the need, how you handle it today and who would use the result. Please do not include passwords, credentials, sensitive files or private customer records.
